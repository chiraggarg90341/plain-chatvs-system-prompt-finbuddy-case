Analysis

2. System prompt performance: The system prompt provides clear instructions about customer safety, personal data, language and response length. This helps FinBuddy follow the bank’s rules more consistently.

4. Closing line: The system prompt specifically instructs FinBuddy to end every answer with “Please confirm with an official source.”

Conclusion

The system prompt provides better control over an AI assistant used in banking. Plain chat is suitable for simple general questions, while a system prompt is more appropriate for business tasks that require consistent rules, privacy and safety.

However, AI responses must always be tested and verified before a bank uses them with real customers.
